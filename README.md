# mailing_management_service  — Работа с базой данных вакансий HH.ru

## Описание проекта

Проект получает данные о вакансиях выбранных работодателей через API HH.ru, сохраняет информацию в базу данных PostgreSQL и предоставляет удобный интерфейс для анализа вакансий.

В рамках проекта реализовано:

* получение вакансий через API HH.ru;
* автоматическое создание базы данных PostgreSQL;
* создание таблиц работодателей и вакансий;
* сохранение данных в базу данных;
* получение статистики по работодателям и вакансиям;
* поиск вакансий по ключевым словам;
* вычисление средней заработной платы.

## Функциональность

После запуска программа:

1. Создает базу данных `vacancies_db`.
2. Загружает вакансии выбранных компаний через API HH.ru.
3. Сохраняет работодателей и вакансии в PostgreSQL.
4. Предоставляет консольное меню для работы с данными.

Доступные операции:

* получить список компаний и количество вакансий;
* получить список всех вакансий;
* получить среднюю зарплату по вакансиям;
* получить вакансии с зарплатой выше средней;
* найти вакансии по ключевому слову;
* завершить работу программы.

## Настройка PostgreSQL

Создайте файл `configuration.ini` на основе шаблона:

```bash
cp configuration.ini.example configuration.ini
```

Пример содержимого:

```ini
[postgresql]
host=localhost
port=5432
user=postgres
password=your_password
```

Убедитесь, что PostgreSQL запущен и пользователь обладает правами на создание баз данных.

## Основные классы

### HH

Класс для работы с API HH.ru.

Методы:

* `_connect_to_api()` — отправка запроса к API;
* `load_vacancies()` — получение списка вакансий работодателя.

---

### DBManager

Класс для работы с PostgreSQL.

Методы:

#### get_companies_and_vacancies_count()

Возвращает список компаний и количество вакансий каждой компании.

#### get_all_vacancies()

Возвращает:

* название компании;
* название вакансии;
* зарплату;
* ссылку на вакансию.

#### get_avg_salary()

Возвращает среднюю зарплату по всем вакансиям.

#### get_vacancies_with_higher_salary()

Возвращает вакансии с зарплатой выше средней.

#### get_vacancies_with_keyword(keyword)

Возвращает вакансии, содержащие указанное ключевое слово в названии.
