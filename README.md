# Mailing management service — Сервис управления почтовыми рассылками

## Описание проекта

Веб-приложение на Django для создания и управления почтовыми рассылками.

Сервис позволяет:

* регистрировать пользователей с подтверждением электронной почты;
* создавать получателей рассылок;
* создавать шаблоны сообщений;
* создавать и редактировать рассылки;
* запускать рассылки вручную;
* отслеживать попытки отправки;
* просматривать статистику рассылок;
* разграничивать права доступа между пользователями и менеджерами.

## Основные возможности

### Пользователи

* Регистрация по email
* Подтверждение аккаунта через письмо активации
* Авторизация
* Редактирование профиля
* Загрузка аватара
* Просмотр профиля

### Получатели

Пользователь может:

* создавать получателей;
* редактировать их;
* удалять;
* просматривать список получателей.

Каждый получатель принадлежит конкретному пользователю.

### Сообщения

Пользователь может создавать шаблоны сообщений:

* тема письма;
* текст письма.

### Рассылки

Для каждой рассылки задаются:

* период активности;
* сообщение;
* список получателей;
* статус рассылки.

Поддерживаемые статусы:

| Статус | Описание  |
| ------ | --------- |
| NEW    | Создана   |
| INP    | Запущена  |
| DONE   | Завершена |

### Попытки рассылки

Для каждой отправки сохраняется:

* дата и время попытки;
* статус выполнения;
* ответ почтового сервера;
* получатель письма.

---

## Права доступа

### Обычный пользователь

Может:

* работать только со своими объектами;
* создавать и запускать рассылки;
* просматривать собственную статистику.

### Менеджер

Дополнительные возможности:

* просмотр всех пользователей;
* просмотр всех рассылок;
* блокировка пользователей;
* блокировка рассылок.

---

## Статистика

На главной странице отображаются:

* общее количество рассылок;
* количество активных рассылок;
* количество уникальных получателей.

В личном кабинете доступны:

* количество успешных отправок;
* количество неудачных отправок;
* общее количество отправленных сообщений.

## Установка проекта

### Клонирование репозитория

```bash
git clone git@github.com:LeslieShmit/mailing_management_service.git
cd mailing_management_service
```

### Установка зависимостей

```bash
poetry install
```

### Активация окружения

```bash
poetry shell
```

---

## Настройка переменных окружения

Создайте файл `.env` на основе шаблона:

```bash
cp .env.sample .env
```

Пример содержимого:

```env
SECRET_KEY=your_secret_key

DEBUG=True

NAME=mailing_db
USER=postgres
PASSWORD=postgres
HOST=localhost
PORT=5432

EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_HOST_USER=your_email
EMAIL_HOST_PASSWORD=your_password

REDIS_HOST=localhost
REDIS_PORT=6379
```
